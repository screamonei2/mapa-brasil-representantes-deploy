Teste: Detecção de Municípios - CORRIGIDO

Problema Identificado e Corrigido

❌ PROBLEMA ORIGINAL:
O sistema estava detectando cliques na cidade do Rio de Janeiro como sendo em um estado, não em um município.

🔍 CAUSA:
A função handleGlobalMapClick só verificava municípios se municipiosLayer existisse. No modo 'states' (visualização geral do Brasil), essa camada não existe, então o sistema não conseguia detectar cliques em municípios.

📍 COORDENADAS PROBLEMÁTICAS:
lat: -22.978623970384902, lng: -43.5882568359375
Estas são coordenadas da cidade do Rio de Janeiro, mas o sistema estava detectando como estado.

Correção Aplicada

✅ SOLUÇÃO IMPLEMENTADA:
Modifiquei a lógica para que, mesmo no modo 'states', o sistema possa detectar cliques em municípios usando os dados disponíveis em municipiosData.

🔧 MUDANÇAS TÉCNICAS:
1. Verificação expandida: Agora verifica se municipiosLayer OU municipiosData estão disponíveis
2. Detecção em duas etapas: Primeiro tenta detectar visualmente (se a camada existir), depois busca nos dados brutos
3. Estrutura de dados melhorada: clickedMunicipio agora inclui informações sobre o tipo de detecção
4. Seleção visual condicional: Só tenta atualizar seleção visual se a camada existir

📊 FLUXO CORRIGIDO:
Clique → Verificar municípios (visual + dados brutos) → Se encontrou município → Processar município → Se não encontrou → Verificar estados
